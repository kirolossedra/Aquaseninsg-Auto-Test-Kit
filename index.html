POST Receiver

The static HTML page does not receive POST requests. Firebase Realtime Database receives them. 

POST endpoint:
https://test-c7bf3-default-rtdb.firebaseio.com/alerts.json

Required JSON body:
{
  "kitOwner": "Owner Name",
  "sensorId": "SENSOR-001",
  "powerSentAt": {
    ".sv": "timestamp"
  }
}

Security note: this exposes the Firebase project configuration in the browser, which is normal for Firebase web apps. Real protection depends on your Firebase Realtime Database rules. If public writes are allowed, anyone with the endpoint can submit alerts.
